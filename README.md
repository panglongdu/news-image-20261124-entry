# The World in One Day — 24 November 2026

Entry for make.fun bounty `news-image-20261124`: sum up 24 November 2026's
world news in one image.

`main.py` copies `entry.png` (1024×1024) to the output directory
(`MAKEFUN_OUTPUT_DIR` or `/output`). The image is drawn by
`build_image.py` (Pillow) as a front-page style summary of the day's
headlines: Ukraine's sea-drone strike on a Russian warship off Libya,
Jensen Huang's return to Nvidia, tankers burning in the Strait of Hormuz,
NATO space defence, South Korea scrambling jets, the US midterm House
result, and more.
