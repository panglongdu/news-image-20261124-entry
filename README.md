# The World in One Day — 24 November 2026

Entry for make.fun's [“Sum up 24 November's world news in one image”](https://make.fun/bounty/news-image-20261124) bounty.

`main.py` copies `entry.png` (1024×1024) to the output directory
(`MAKEFUN_OUTPUT_DIR` or `/output`). Run it with:

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The image is drawn by `build_image.py` (Pillow) as a front-page style
summary of the day's headlines: Ukraine's sea-drone strike on a Russian
warship off Libya, Jensen Huang's return to Nvidia, tankers burning in
the Strait of Hormuz, NATO space defence, South Korea scrambling jets,
the US midterm House result, and more.
